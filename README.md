Solmar City is a 2D top-down open-world crime game: walk and drive around a living city, steal cars, outrun the police, and run six story missions for fixer Rosa Delgado — plus taxi fares and hidden packages to find.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
